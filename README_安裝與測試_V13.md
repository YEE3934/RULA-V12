# RULA V13：疑似離平面／2D 投影品質篩檢與局部人工覆核（測試版）

## 版本定位

這是以 V12 完整 `222.py` 為基礎製作的 **完整測試版**，保留原有 RULA 計分、三視角同步、Hand 偵測、人工覆核、圖表和原始 ZIP 報表。新增的 V13 研究模組 **不會更改正式 RULA Grand Score / Action Level 或任何已存在的人工修正**。正式穩定版本請先備份；不要未測試就取代。

V13 **不是已驗證的離平面分類器**，不會得到真正的三維角度或宣稱辨識出實際旋轉多少度。「疑似離平面」只是觀測到2D投影不可靠的**可能原因**；同樣的警示也可能由遮擋、骨架錯位、同步偏差或演算法假設造成。

## 檔案

- `222.py`：完整 Streamlit 主程式，含 V12 + V13 整合
- `angle_lab_core.py`：V12 既有鏡頭角度候選、品質篩選
- `rula_cross_view_bridge.py`：V12 正式分數隔離／研究試算橋接
- `v13_oop_review.py`：新增 V13 品質證據、局部人工覆核決策、ZIP 匯出
- `requirements.txt`、`packages.txt`、`.streamlit/config.toml`：部署依賴
- `tests/`：現有測試與新 V13 測試
- `scripts/`、`models/`、`timeline_component/`：完整既有系統所需檔案

## 部署方法

1. 在 GitHub **新建測試 Repository**（例如 `RULA-V13-Test`），不要直接覆寫原有正式站。
2. 把本壓縮檔解壓後所有檔案和子資料夾上傳至測試 Repository 根目錄，包含 `.streamlit`、`timeline_component` 和 `tests`。
3. 在 Streamlit Community Cloud 建立新 App，Main file path 填 **`222.py`**，建議 Python 3.11。
4. 等部署完成後確認 build tag 為 `RULA_222_V13_OOP_QUALITY_RESEARCH_2026-11-06`。
5. **不要把只支援其他 Python/NumPy 版本的套件隨意升級**；`requirements.txt` 保留原 V12 的依賴。

## 實際測試順序

1. 用之前同一段搬運作業的 **Front / Left / Right 三個原始影片**。
2. 依正式系統的步驟設定分析側、抽樣張數和同步偏移；確保鏡頭影像未水平鏡像。
3. 在分析設定中勾選「V12 跨視角角度研究」與「V13 疑似離平面／2D 投影品質初篩＋人工局部覆核紀錄」。
4. 第一次先用 5–10 張做試跑，確認沒有錯誤，再改成之前的30張，才能和人工表比較。
5. 分析完成到 **🧪 跨視角研究** 分頁，向下滑到「V13｜疑似離平面與量角品質警示」。
6. 檢查第18張（**樣本編號需與相同影片實際秒數確認**）的人體左側前臂：檢查是否有警示、警示依據是肩線／可見度／肢段投影／跨鏡頭差異中的哪一項。沒有警示也不代表已證實量角正確。
7. 選擇一張需要處理的「樣本／人體側別／部位」，人工比較三個同步視角原圖，再選擇「原角度可用／替代側向角度可用／無可靠角度但仍可分級／無法可靠評估」。有需要再填人工確認角度與備註，**按保存**。
8. 到 📦 下載分頁下載報告 ZIP，確認多出 `Diagnostics/V13_疑似離平面與量角品質篩檢.csv`、`Diagnostics/V13_人工局部覆核決策.csv`、`Diagnostics/V13_使用限制與統計說明.txt`。
9. 檢查正式 RULA 分數是否與 V12 完全相同。這是版本相容性最重要的驗收。

## 功能能做什麼／不能做什麼

| 功能 | V13 有無 | 說明 |
|---|---|---|
| 全部影格兩側的前臂／頸部品質初篩 | 有 | 與 V12 取得候選角度並行 |
| 顯示疑似離平面／遮擋／投影風險的具體證據 | 有 | 只是探索性品質警告，不是3D真值 |
| 比較同一人體側別、同一時間點的不同側向鏡頭候選角 | 有 | 保留來源、分別顯示 |
| 正面視角直接替代前臂屈伸或頸部前屈角 | **沒有** | 禁止直接替代 |
| 自動確認某個影格真正已離平面 | **沒有** | 尚需獨立3D量測與人工標註驗證 |
| 自動換鏡頭並覆寫正式RULA評分 | **沒有** | 只有V12研究候選試算，避免未驗證改分 |
| 人工判定角度可用／不可用，分開記錄RULA級距可否確認 | 有 | 必須人工保存覆核決策 |
| 自動剔除無法量角的整張影格 | **沒有** | 只加註角度及RULA評估狀態；保留原紀錄 |
| 經標定的3D重建 | **沒有** | 不可宣稱3D真實角度 |

## 品質線索（探索性，非真值）

- 原側面肩寬／軀幹長投影比例偏寬（初始門檻0.55，且肩點可見度不低於0.35）。
- 前臂／上臂2D投影長度比例不合理（小於0.40或大於2.70）。
- 原視角肘腕關節可見度偏低（小於0.55）。
- **同一人體左／右側**於兩個側面鏡頭的前臂角差≥20°、頸部角差≥15°。
- 兩側面肘腕投影相對長度比小於0.60。

以上門檻只是工程探索值，不是對不同人體或鏡頭都有效的辨識標準。應以人工標註的疑似問題案例計算警示召回率與誤報率，再做調整。這些規則可能漏掉很多實際離平面樣本，請不要寫成「全部辨識」。

## 論文資料處理

- **角度 MAE**：只有在人工參考角度可靠且角度定義與系統相同時，才能納入主要角度MAE；不可因某張誤差大就任意排除。
- **姿勢分級**：角度無法可靠量測時，若同步三視角仍能支持RULA分級，可保留該分級，但不要假裝有真實角度。
- **總分一致率**：若完整RULA姿勢條件無法確定，記錄「無法可靠評估」及覆核原因；不要將系統暫算分數直接當作已驗證正確。
- **保留分母**：總樣本數、品質警示數、覆核數、角度失效筆數、RULA失效筆數及人工比對有效筆數都應同時報告。
- **基準**：V13 的品質警示不會改變 V12 既有總分，因此單靠 V13 啟用不能宣稱一致率或MAE已改善。
